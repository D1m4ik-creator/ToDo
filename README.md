# ToDo

## Быстрый запуск

```bash
docker compose up -d --build
```

После старта:
- Frontend: `http://127.0.0.1:5000`
- Backend API: `http://127.0.0.1:8000/api/`
- Swagger (OpenAPI): `http://127.0.0.1:8000/api/docs/`

## Как работает проект

- `frontend/` — клиент на vanilla JS: авторизация, команды, проекты, Kanban-доска, уведомления, чат.
- `problems/app/` — REST API (Django + DRF): пользователи, команды, проекты, задачи, уведомления.
- `problems/WS/` — WebSocket-чат (Django Channels + JWT в query-параметре).
- `redis/` + `celery` — фоновые задачи и события (например, уведомления/инвайты).
- `db` (PostgreSQL) — основное хранилище данных.

Основной флоу:
1. Пользователь логинится и получает JWT.
2. Создает команду и проекты внутри команды.
3. Создает/двигает задачи по статусам (`todo -> progress -> review -> done`).
4. Приглашает участников по dynamic ID, участники принимают/отклоняют приглашения.
5. Уведомления читаются через REST, чат работает через WebSocket.
